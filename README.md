# Sadek Bot v2 — قلب صغير + إضافات سهلة

بوت واتساب بهيكل جديد: **قلب ثابت صغير** يملك الاتصال والخدمات، و**مجلد plugins** فيه كل الميزات والمصادر — كل إضافة ملف واحد مستقل، سهلة التعديل والحذف والإضافة.

## الخريطة

```
index.js          القلب: اتصال واتساب + تحميل الإضافات + توجيه الرسائل (نادراً ما يُلمس)
core/             الخدمات السبع الثابتة:
  messenger.js      1) الرسائل والردود
  wizard.js         2) القوائم والاختيار (أرقام، حلقات، نطاقات 1-15، جودات)
  download.js       3) التحميل (أجزاء متحقَّق منها، لا دمج أبداً)
  record.js         4) التسجيل (بث مباشر، نسخ مباشر، أجزاء بالدقائق)
  fetch.js          5) الجلب (صفحات وAPI)
  extract.js        6) أدوات الاستخراج (m3u8، فك الحزم، أحجام، بوستر مضغوط)
  store.js          7) الحفظ (data/)
  loader.js           محمّل الإضافات (يعزل أي إضافة مكسورة ويكمل)
  sourceflow.js       محرك أوامر البحث (.anime/.series/.movie/.kdrama)
plugins/          ملعبك: كل ملف = مصدر أو أمر
  anime/  series/  tools/     مجموعات حسب النوع
  _templates/                 الهيكل الموحّد (قوالب لا تُحمَّل)
data/config.json  الإعدادات: رقم الهاتف للربط، اسم البوت، حجم الجزء
session/          جلسة واتساب (تُحفظ تلقائياً)
```

## كيف تضيف مصدراً جديداً (باش)

1. انسخ `plugins/_templates/TEMPLATE.sh` إلى مجلد النوع المناسب، مثال: `plugins/anime/mysite.sh`
2. عدّل سطرَي `NAME:` و`TYPE:` في الرأس.
3. املأ المراحل الثلاث بمنطق موقعك (curl + grep كما تعرف):
   - `SEARCH` يطبع: `العنوان | المعرّف`
   - `EPISODES` يطبع: `COUNT العدد` أو سطور الحلقات
   - `LINKS` يطبع: `الجودة | الرابط`
4. ادفع الملف إلى GitHub وأرسل `.reload` للبوت (أو أعد تشغيله) — انتهى. يظهر المصدر فوراً في `.anime` أو `.series` حسب نوعه.

مثال جاهز وشغال على نفس الهيكل: `plugins/anime/anime3rb.sh`.

## كيف تضيف أمراً (Node)

انسخ شكل TEMPLATE.js إلى ملف جديد في plugins — إما مصدر (search/episodes/links) أو أمر مستقل (commands + handle).

## التشغيل أول مرة

1. ارفع محتويات هذا المشروع إلى مستودع GitHub جديد.
2. للربط اختر واحدة:
   - **الأسهل:** انسخ مجلد `session/` من مستودع بوتك الحالي كما هو — يعمل مباشرة (لا تشغّل البوتين معاً بنفس الجلسة).
   - **أو:** ضع رقمك بصيغة دولية (أرقام فقط) في `data/config.json` في حقل `phone`، وشغّل الـ workflow، وستجد رمز الربط (Pairing Code) في سجل التشغيل (Logs) — أدخله في واتساب > الأجهزة المرتبطة.
3. من Actions شغّل workflow باسم **Bot**.

## أوامر مدمجة

- `.help` — القائمة (تتولد تلقائياً من الإضافات المحملة)
- `.plugins` — ما تم تحميله فعلاً
- `.reload` — إعادة فحص مجلد plugins دون إعادة تشغيل كاملة
- `.stoprec` — إيقاف تسجيل جارٍ
- `.ping` — فحص سريع
- `.anime / .series / .movie / .kdrama <اسم>` — بحث في كل مصادر النوع
- `.dl <رابط>` — تحميل من رابط مباشر (إضافة مثال في plugins/tools)

## قاعدة الصيانة الذهبية

- ما ينكسر غالباً (المصادر) يعيش في plugins — ملفات صغيرة بلغتك.
- القلب ثابت: عطل في إضافة واحدة لا يوقف البوت (تُتخطى وتُسجَّل).
- نسخة أخيرة شغالة دائماً في متناول يدك عبر سجل Git.
